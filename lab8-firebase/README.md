# Lab 8 - Firebase Authentication & Firestore Database

## 项目功能

### 1. Firebase Authentication
- ✅ 用户注册（带角色选择）
- ✅ 用户登录
- ✅ 用户登出
- ✅ 多角色支持（user/admin/guest）

### 2. 书籍管理系统
- ✅ 添加书籍（Add Book）
- ✅ 查看书籍列表
- ✅ 更新书籍信息
- ✅ 删除书籍

### 3. 高级查询功能
- ✅ 使用where条件查询
- ✅ 使用orderBy排序
- ✅ 使用limit限制结果
- ✅ 组合查询（where + orderBy + limit）

### 4. 技术栈
- Vue.js 3
- Firebase Authentication
- Firebase Firestore
- Vue Router
- Bootstrap CSS

## 运行项目
```bash
npm install
npm run dev
```

## 项目结构
- `src/views/` - 页面组件
- `src/components/` - 可复用组件
- `src/router/` - 路由配置
- `src/stores/` - 状态管理
